# Cadastro de Produto

API REST em Spring Boot para cadastro de produtos, com persistência em PostgreSQL.

## Endpoints

- `GET /v1/get` — lista todos os produtos
- `GET /v1/{id}` — busca produto por ID
- `POST /v1/list_products` — cadastra produto
- `PUT /v1/{id}` — atualiza produto
- `DELETE /v1/{id}` — remove produto
